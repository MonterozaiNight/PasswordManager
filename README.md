<h1>パスワードマネージャー</h1>

Pythonで開発した簡易的なパスワードマネージャーです。

## プロジェクトについて

公開鍵方式の暗号化を使ったパスワードマネージャーです。<br/>
パスワードを自動生成し、暗号化パスワードとログインIDをJSONファイルで保存する仕組みです。<br/>
<br/>
暗号化にはRSA暗号方式を使用しています。<br/>
また、鍵ファイルに使用しているパスフレーズも鍵導出関数のkdfを使用して暗号化しています。
<br/>
暗号化・復号化の学習、パスワード管理するのにお役立てください。

## 使い方

実行した際に、出てくるフォームの入力手順を説明します。<br/>

1, 認証情報登録に関して<br/>
①パスフレーズ復号化用マスターパスワード欄に鍵ファイルに設定するパスフレーズ暗号化用のパスワードを入力します。<br/>
②すぐ右側の[パスフレーズ生成]ボタンを押下します。<br/>
③「パスフレーズが正常に保存されました。」と表示されますので、下のログインID(もしくはEメールアドレス)を入力します。<br/>
④ログインID入力後、ログインID入力欄の右にある[パスワード生成]ボタンを押下して、パスワード入力欄に自動生成パスワードを入力させます。<br/>
⑤④までの手順を全て実施しましたら、一番下の[認証情報登録]ボタンを押下してください。<br/>
⑥パスワードマネージャーを保存したフォルダの直下にpassphrase.json(暗号化パスフレーズ保存用JSON)、credentials.json(ログインID暗号化パスワード保存用JSON)、private_key.pem(秘密鍵)、public_key.pem(公開鍵)が保存されます。<br/>
